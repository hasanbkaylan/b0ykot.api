# Katkıda Bulunma Rehberi

`b0ykot.api` projesine katkı sağlamak çok kolaydır. İki farklı yöntemle listelere ekleme veya düzeltme yapabilirsiniz:

## Yöntem 1: Doğrudan Dosya Düzenleme (Pull Request)
1. Sağ üstten repoyu **Fork** edin veya doğrudan düzenlemek istediğiniz dosyayı (`boykot.txt` veya `boykotdegil.txt`) açın.
2. Dosyanın sağ üstündeki **kalem (Edit this file)** simgesine tıklayın.
3. Yeni markayı alt satıra ekleyin.
4. Sayfanın altından **Commit changes** diyerek **Pull Request (PR)** oluşturun.

### Dikkat Edilecekler
- Aynı markayı hem `boykot.txt` hem de `boykotdegil.txt` dosyasına yazmayın (otomatik sistem PR'ı reddedecektir).
- Markanın aksansız/boşluksuz yazımlarını ekstra eklemenize gerek yoktur; sistem API oluştururken varyasyonları otomatik üretir.
- PR açıklamasında markanın üretici firmasını veya kaynağını kısaca belirtmeniz onay sürecini hızlandırır.

## Yöntem 2: Form Doldurarak Öneri Gönderme (Issues)
GitHub dosya düzenleme adımlarıyla uğraşmak istemiyorsanız, üst menüden **Issues -> New Issue -> Marka Ekleme / Düzeltme Talebi** formunu doldurarak öneri bırakabilirsiniz.
